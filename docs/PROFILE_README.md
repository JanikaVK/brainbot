# JanikaVK

## Featured project

### [BrainBot](https://github.com/JanikaVK/brainbot)

A student wellbeing Android application with private check-ins, descriptive trends, an encrypted journal, support requests, and an optional machine-learning inference service.

**Built with:** Expo / React Native, Spring Boot, FastAPI, MySQL, Docker Compose.

**Project status:** Development build. Student flows and CI checks are implemented. The ML endpoint is intentionally unavailable until a verified dataset and reviewed model are provided. It is not a deployed service or clinical product. See the repository README for setup and current limitations.
