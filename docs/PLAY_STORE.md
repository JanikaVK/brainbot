# Play Store preparation

Initial Expo application id: `org.brainbot.wellness` (confirm ownership before publication). Expo SDK 57 targets Android API 36, matching Google's current requirement for new app submissions from August 31, 2026. Check the [official target API level requirement](https://developer.android.com/google/play/requirements/target-sdk) again immediately before release. The Expo Android project uses version name/code defaults until a release process is established. Generate a native Android project with `npx expo prebuild --platform android`, configure adaptive icon and splash assets, then create a signed Android App Bundle using a signing key stored outside Git.

Before submission, verify current account verification, privacy policy, Data safety answers, content rating, health apps declaration, permission declarations, account deletion requirements, and testing-track requirements against official Play Console documentation. Health and wellness apps must complete the [Health apps declaration](https://support.google.com/googleplay/android-developer/answer/14738291?hl=en) and provide an accessible privacy policy under [health app policy](https://support.google.com/googleplay/android-developer/answer/16679511?hl=en). Because this app creates accounts, implement in-app and web account deletion with deletion of associated data per [account deletion requirements](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en) before publication. Collect only necessary data and accurately disclose processing/sharing/retention. No release build, icon, privacy policy URL, signing key, account-deletion workflow, or Play review has been completed; this is not publishable.
